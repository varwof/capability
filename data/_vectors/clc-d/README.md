# CLC-D containment vectors

Machine-readable conformance vectors for **CLC-D** (the delegation containment
relation, [`capability-language-core-v1.md`](../capability-language-core-v1.md) §13.4/§13.7,
folded in rev CLC-1.9 and formerly `draft-wei-clc-ext-00`).
These are the single source of truth used by the three implementations:

- Go: [`varwof/register`](https://github.com/varwof/register) →
  `cmd/contains-vectors-run`, `go test ./semantics/ -run TestContains`
- Python: [`varwof/aic-capability-demo`](https://github.com/varwof/aic-capability-demo) →
  `contains-vectors-run.py`, `contains_test.py`
- TypeScript: [`varwof/aic-capability-demo/ts`](https://github.com/varwof/aic-capability-demo/tree/main/ts) →
  `contains-vectors-run.ts`, `contain-property.ts`

CLC-D is **additive**: it does not change any CLC-A verdict, reason code, or
vector.  The CLC-A corpus lives in [`../clc-v1/`](../clc-v1/).

## Files

| File | Purpose |
|---|---|
| `containment-vectors.json` | **64** vectors: `Contain(P, C)` verdict + resolved reason across draft §4 layers 1–4, plus symmetry probes |
| `containment-property-cases.json` | **784** cases × **39** shared operations: the forward-closure property (generated by `capability/scripts/gen-contain-property-cases.py`) |
| `containment-crosswalk-vectors.json` | **44** vectors: a carrier's native representation mapped to CLC grants on each side, then `Contains` — the attenuation analogue of the CLC-A cross-walk.  Carriers: AIC-JWT DA, OAuth RAR, UCAN, delegation chain, plus the adjacent agent drafts ATN (`draft-somoza-dmsc-atn-agent-trust-negotiation`), AAT (`draft-niyikiza-oauth-attenuating-agent-tokens`), AIP (`draft-prakash-aip`), AAE (`draft-kroehl-agentic-trust-aae`), AOA (`draft-liu-agent-operation-authorization`), and AEGIS AIAM-1.  Profile obligations (identity dimensions, inheritance resolution, no invented semantics) are §13.8.1 of the core; the vocabulary and reason-code mapping is Appendix C |
| `containment-vectors.schema.json` | JSON Schema for `containment-vectors.json` (each vector carries `ext_revision` and `conformance_class: CLC-D`) |
| `authorize-chain-vectors.json` | **15** vectors for the §13.11 fused `AuthorizeWithChain` (rev CLC-1.13/1.14): containment per hop then `Authorize(Intersect(chain))`, with `authorize-chain-vectors.schema.json`; `ac-012`/`ac-015` pin a `param_bounds` chain (§6.6 meet) |

## Running

```bash
# Go (from the register repository)
CLC_D_VECTORS=../capability/data/_vectors/clc-d/containment-vectors.json go run ./cmd/contains-vectors-run/
CLC_D_PROPERTY_CASES=../capability/data/_vectors/clc-d/containment-property-cases.json \
  go test ./semantics/ -run TestContainsProperty -v
CLC_D_CROSSWALK_VECTORS=../capability/data/_vectors/clc-d/containment-crosswalk-vectors.json \
  go run ./cmd/contains-crosswalk-run/

# Python (from the aic-capability-demo repository)
CLC_D_VECTORS=../capability/data/_vectors/clc-d/containment-vectors.json python3 contains-vectors-run.py
CLC_D_PROPERTY_CASES=../capability/data/_vectors/clc-d/containment-property-cases.json python3 contain-property-run.py

# TypeScript (from the aic-capability-demo repository)
CLC_D_VECTORS=../capability/data/_vectors/clc-d/containment-vectors.json \
  node --experimental-strip-types ts/contains-vectors-run.ts
CLC_D_PROPERTY_CASES=../capability/data/_vectors/clc-d/containment-property-cases.json \
  node --experimental-strip-types ts/contain-property.ts
```

Every runner asserts **both the `contains` verdict and the resolved reason
code** (the part before the first `:`) and exits non-zero on any mismatch.

## Run contract

- A vector is `{ parent, child, expect: { contains, reason? } }`.  `reason` is
  asserted only on a `false` result; a `true` result carries no reason.
- The reason codes are the CLC-D codes (`child_exceeds_parent`,
  `params_not_narrower`, plus the carrier-level `delegation_mode_not_narrower`)
  and the CLC-A codes a layer-1/layer-2 failure reuses
  (`unsupported_wildcard`, `missing_capability_id`, `invalid_params_null`,
  `different_namespace`).
- **Constraints are not part of the relation.**  `Contains` compares identifier
  and parameters only.  Constraints compose by **union** (conjunction) across a
  delegation chain (`Intersect`, CLC-A §7), never by subset, so a constraint
  difference never changes a `Contains` verdict.  The vectors that vary
  constraints all assert `contains: true` for exactly this reason; constraint
  grammar is validated by the consumer/`Intersect`, not here.
- **Layer 5 (delegation mode) is not in the language corpus.**  `Contains(GP, GC)`
  takes no mode; a carrier that binds one (AIC-JWT DA, core §13.8) MUST carry its
  own mode vectors.
- **Forward closure** is the property the property corpus checks: for every
  case and every operation `o` in `ops`, `Contains(P, C)` must not raise, and
  `Contains(P, C) ∧ Entails(C, o) ⟹ Entails(P, o)`.
- **Cross-walk** vectors (`containment-crosswalk-vectors.json`) map a carrier's
  native representation to a CLC grant on each side (via the same
  `MapProfile` profiles as the CLC-A cross-walk) and assert the `Contains`
  result.  A profile that maps a side to more than one grant is a map error:
  containment is a relation over single grants.

## Independence

The parity bar and honesty rule of CLC-A §12 apply unchanged: agreement between
implementations that share an author is a regression test for the extension
text, not independent validation.  Third-party implementations are invited to
run the corpus with the spec and their own semantics; verified parity is the
CLC-D conformance bar.

## Adding a vector

1. Add the case with `id`, `kind: "contain"`, `spec_clause`, `ext_revision`,
   `conformance_class`, `parent`, `child`, `expect` and a one-line `derivation`.
   Every vector MUST cite a clause that exists in the draft.
2. Validate against `containment-vectors.schema.json`.
3. Run all three runners; if they disagree with the expectation, decide whether
   the draft is ambiguous (record it) or an implementation is wrong — never
   adjust the vector to make a run pass.

Regenerate the property cases deterministically with:

```bash
python3 ../../../scripts/gen-contain-property-cases.py
```
